### Challenges and Problems Encountered

**Biggest Challenge:**

As a beginner using Arduino IDE and Arduino UNO for the first time, my biggest challenge was understanding how software interacts with hardware. Although I had some programming experience in C, I was unfamiliar with Arduino pins, sensor connections, and hardware control.

**How I Overcame It:**

I broke the project into smaller tasks. First, I focused on reading EMG data from the BioAmp EXG Pill and displaying the values on an OLED screen. After that, I added a buzzer and a vibration motor to provide alerts when the EMG readings exceeded certain thresholds.

I tested each function separately before combining them into one program.

**Problems Encountered:**

1. **OLED Display:** Initially, the OLED screen did not display the EMG readings correctly. I needed to troubleshoot the code, display initialization, and hardware connections.
2. **Buzzer and Vibration Motor:** I had to learn how to use conditional statements to activate different hardware components based on sensor readings.
3. **Threshold Adjustment:** The initial EMG thresholds needed adjustment during testing. I modified the vibration thresholds to below 350 or above 680.
4. **GitHub Organization:** I initially had difficulties creating folders and organizing Arduino files on GitHub. After some trial and error, I successfully organized my EMG testing code.

**What I Learned:**

Through this experience, I learned the basics of Arduino programming, sensor integration, hardware debugging, and GitHub file management.

Most importantly, I learned that building a hardware project requires continuous testing, troubleshooting, and improvement.
